# Corper Wee

A realistic 3D life simulator of the Nigerian service year: call-up, orientation camp, PPA, CDS and passing out.
Fictional game. Not affiliated with NYSC or the Federal Government of Nigeria.

Publisher: Swiftmynd Technologies Ltd · Engine: Unity 6 (6000.0 LTS), C# · Android first.

## What's in this build

**Orientation camp (21 days)**
- 3D camp made in Blender. You can walk into the hostels (bunk beds, boxes, buckets, fans), multipurpose hall
  (stage, rows of chairs), kitchen, camp office, clinic, mosque and chapel. Roofs lift off and the camera looks
  down into the room when you go inside. Parade ground, Mammy Market, SAED tents, football pitch, Man O' War.
- Character creator; mufti until kit collection, then camp whites (white T-shirt, white shorts, canvas shoes).
- Real camp timetable from the 4:30am bugle, needs (energy, food, health, mood, hygiene), naira, soldiers'
  punishments, drill rhythm game, lecture quiz, 28 camp events, posting letter.

**Service year (12 months, 6 days each)**
- 3D town: corpers' lodge (rooms with mattresses), Government Secondary School (desks, blackboard),
  TechHub Limited (desks and monitors), General Hospital (wards), Local Government Secretariat,
  NYSC LGI office, community hall for CDS, Mama T Buka, bank and ATM, market, motor park with danfos and kekes.
- Housing choice (free lodge, shared room, self-contain) with monthly rent.
- PPA work shifts, attendance and PPA reputation; retention offers for strong performers.
- Weekly CDS, monthly clearance at the LGI office, allawee (federal + state + PPA stipend) only if cleared.
- Side hustles based on your SAED skill, POS business, personal CDS project (borehole, library, outreach).
- 21 service-year events (NEPA, landlord, bribe attempt, owambe, black tax, malaria, job fair...).
- Passing out with seven endings (retained, business owner, master's abroad, government job, state award,
  job hunting, service extended) and a WhatsApp share button.
- Developer pop-up in the pause menu (rate, WhatsApp, buy me a coffee, hire the developer).

Next: AdMob and Play Billing, voice lines, more towns (northern town, village PPA).

## Project layout

```
Assets/Scripts/Core       game state, save, game manager, bootstrap
Assets/Scripts/Systems    needs, money, timetable, events, location actions, story
Assets/Scripts/UI         HUD, dialogs, joystick, character creator (all built in code)
Assets/Scripts/Player     movement, camera, procedural walk animation
Assets/Scripts/World      camp loader, NPC corpers, day-night cycle
Assets/Scripts/MiniGames  drill and lecture quiz
Assets/Editor             build script (creates the scene and builds the APK), model import settings
Assets/Resources/Models   camp.fbx and corper.fbx (generated by tools/blender)
Assets/Resources/Data     events and quiz JSON: add content here without code changes
tools/blender             Python scripts that build the 3D models (pip install bpy)
docs/previews             renders of the models
```

Rebuild the models: `pip install bpy && python3 tools/blender/build_camp.py && python3 tools/blender/build_corper.py`
(add `--render` for preview images).

## Automatic APK builds (GitHub Actions)

Every push to `main` builds an APK with GameCI. Download it from the run's **Artifacts**.
It needs three repository secrets (Settings → Secrets and variables → Actions):

| Secret | Value |
| --- | --- |
| `UNITY_EMAIL` | the email of your free Unity account |
| `UNITY_PASSWORD` | its password |
| `UNITY_LICENSE` | full text of your `Unity_lic.ulf` file |

To get `Unity_lic.ulf` (one time, on any Windows or Mac PC):
1. Create a free account at unity.com and install **Unity Hub**.
2. Sign in to Unity Hub, go to **Preferences → Licenses → Add → Get a free personal license**.
3. Open the licence file and copy everything inside:
   - Windows: `C:\ProgramData\Unity\Unity_lic.ulf`
   - Mac: `/Library/Application Support/Unity/Unity_lic.ulf`

## Open in the Unity editor (optional)

Open the folder with Unity 6000.0 LTS, then menu **Corper Wee → Create Main Scene** and press Play.
